*** Creating a Window
To create a [[doc:window][=window=]] ([[https://developer.apple.com/documentation/appkit/nswindow?language=objc][=NSWindow=]]) instance:

#+name: example:create-window
#+begin_src lisp
  (defvar win
    (make-instance 'window
                   :title "My Window"
                   :width 400 :height 400))
#+end_src

#+RESULTS: example:create-window
: win

*Explain*:
+ this creates a [[doc:window][=window=]] instance with [[doc:default-frame][=default-frame=]]

+ the [[doc:window][=window=]] is [[doc:framed-mixin][=framed-mixin=]], which provides abilities to
  initialize with handy frame description keywords,
  for example, the =:width=, =:height= initarg could be
  replaced with syntax sugar like:

  #+name: example:create-window-with-size
  #+begin_src lisp :eval no :exports code
    (make-instance 'window :size #(400 400))
  #+end_src

  also, it is possible to specify =:location=, =:x=, =:y=, =:origin=,
  or directly setting the initial frame with =:frame= key.

To create widgets ([[doc:base-view][=base-view=]]) instances, for example,
a [[doc:button][=button=]]:

#+name: example:create-button
#+begin_src lisp :exports code
  (defvar but
    (make-instance 'button
                   :title  "Button"
                   :frame  #(20 20 350 30)
                   :parent win
                   :font   (make-font :family :fix)
                   :action (lambda (self sender)
                             (alert (format nil "Clicked ~A (sender=~A)"
                                            self sender)))))
#+end_src

#+RESULTS: example:create-button
: but

*Explain*
+ [[doc:button][=button=]] use [[doc:target-mixin][=target-mixin=]],
  the =:action= could be a =function=, [[../objc/readme.org::doc:sel][=sel=]] (or =string= of [[../objc/readme.org::doc:sel][=sel=]]),
  by default the =:target= would be set to be =but= itself

+ use [[doc:make-font][=make-font=]] to create a [[doc:font][=font=]]

+ [[doc:alert][=alert=]] popup a [[https://developer.apple.com/documentation/appkit/nsalert?language=objc][=NSAlert=]]

  + LOCATION:
