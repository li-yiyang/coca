#+subtitle: Minimal CFFI ObjC bindings

* Usage
:PROPERTIES:
:header-args:lisp: :package coca.objc :results verbatim
:END:

** Invoke
Invoke ObjC method with macro =invoke=:

#+begin_src lisp
(description (invoke "NSString" "stringWithUTF8String:" :string "Hello World" :object))
#+end_src

#+RESULTS:
: Hello World

Or use the shortcut function:

#+begin_src lisp :results silent
(cffi:foreign-funcall "NSLog" :pointer (string-to-ns-string "Hello World"))
#+end_src

which should print out like:

#+begin_example
2026-03-10 20:42:23.575 sbcl[21728:11113876] Hello World
#+end_example

Note that ObjC errors are not handled by lisp, which just kills the lisp
image. Be aware to call ObjC methods correctly or check before calling.

** Typing
The macro =invoke= is just a thin warpper on =cffi:foreign-funcall=.

*** ObjC typing via alias
For example:

#+begin_src lisp :eval no
(invoke "NSString" "stringWithUTF8String:" :string "Hello World" :object)
#+end_src

would be expanded into

#+begin_src lisp :eval no
(foreign-funcall
 "objc_msgSend"
 :pointer (objc-class-ptr #<NSString 1F9E6A100>)
 :pointer (sel-ptr #<sel stringWithUTF8String: 20890E8C0>)
 :string "Hello World"
 :pointer)
#+end_src

with typing alias:

#+begin_src lisp :eval no
(define-objc-typing :object
  :alias :pointer)
#+end_src

*** Complex ObjC typing transforming rules
For complex transforming rules:

#+begin_src lisp :eval no
(invoke ns-object "description" :ns-string)
#+end_src

would be expanded into

#+begin_src lisp :eval no
(ns-string-to-string
 (foreign-funcall
  "objc_msgSend"
  :pointer (mcclim-coca.objc::objc-pointer ns-object)
  :pointer (mcclim-coca.objc::sel-ptr #<sel description 208A1BFE0>)
  :pointer))
#+end_src

with result and input args rules:

#+begin_src lisp :eval no
(define-objc-typing :ns-string
  :result (:pointer ns-string-to-string)
  :arg    ((str `(:pointer (string-to-ns-string ,str)))))
#+end_src

the =:arg= parameter can be a list of elements =(PATTERN EXPANSION-RULE)=
+ =PATTERN=: the pattern use [[https://github.com/m2ym/optima][=optima:match=]] to match patterns
+ =EXPANSION-RULE=: an expression evaluated

  the return value(s) can be arg expansion and invoke rewrite
  + arg expansion: should be like a list of =(:CFFI-TYPE EXPR ...)=
  + invoke rewrite: wrap =invoke= like =`(,@rewrite (invoke ...))=

*** Built-in ObjC typing
Coca.ObjC provides some built-in ObjC typing:

| ObjC typing  | CFFI equivent                      | ~invoke~ as return value |
|--------------+------------------------------------+--------------------------|
| ~:class~     | ~:pointer~                         | ~coerce-to-objc-class~   |
| ~:sel~       | ~:pointer~                         | ~coerce-to-selector~     |
| ~:object~    | ~:pointer~                         |                          |
| ~:ns-array~  | ~:pointer~ (not implemented yet)   | ~ns-array-to-list~       |
| ~:ns-string~ | ~:pointer~ (~string-to-ns-string~) | ~ns-string-to-string~    |
| ~:block~     | ~:pointer~ (ObjC's block)          | (not implemented)        |

Can use =define-objc-typing= macro to define a new ObjC typing.

** Block
Some ObjC functions expect blocks as arguments, which can be invoked
like:

#+begin_src lisp :eval no
(invoke obj "methodWithBlock:" :block (BLOCK-TYPE (LAMBDA-LIST) &body ...))
#+end_src

Use =define-objc-block= to define your own =block-type=.

** Image Dump
Since Coca.ObjC is built on ObjC's runtime, every time you terminate
the ObjC runtime, you have to re-initialize it.

Use =define-objc-global-variable= to define a global variable access
function like:

#+begin_src lisp :eval no
(define-objc-global-variable my-ns-string
  (string-to-ns-string "My NSString")
  "Just to demo it")
#+end_src

Use the function =my-ns-string= to access the global variable
=*my-ns-string*= to ensure it would be correctly setted up.

+ =(invoke CLASS-OR-OBJECT SEL [TYPE ARG]* [RETURN-TYPE]?)= [Macro]

  #+begin_src lisp :exports results
  (documentation (macro-function 'invoke) t)
  #+end_src

  #+RESULTS:
  #+begin_example
  Invokes an ObjC method that returns RESULT CFFI type.

  Syntax:

      (invoke CLASS-OR-OBJECT METHOD
              { OBJC-TYPE VAR }*
              [ (RESULT :void) ])

  Parameters:
  + CLASS-OR-OBJECT: things can be converted via `objc-pointer'
  + METHOD: a string naming the method to invoke
  + OBJC-TYPE: extended CFFI type

    Built-in ObjC typing:
    + :object   expecting to be `objc-object'
    + :class    expecting to be `objc-class'
    + :sel      expecting to be `sel'
    + :ns-uint  alias as :unsigned-long
    + :ns-int   alias as :long
    + :cg-float alias as :double

    Built-in ObjC typing in `coca/objc/block' subsystem:
    + :block    expecting (BLOCK-TYPE (lambda-list ...) ,@body)
      see `define-objc-block' for details

    Built-in ObjC typing in `coca/appkit' subsystem:
    + :ns-rect  expecting (X Y W H) inline value passing
    + :ns-point expecting (X Y) inline value passing
    + :ns-size  expecting (W H) inline value passing

    Use `define-objc-typing' to define new ObjC typing.
  + RESULT:

    Built-in ObjC typing:
    + :ns-array return `list' of `foreign-pointer'

    Use `define-objc-typing' to define new ObjC typing.

    If not provided, by default as `:void'

  #+end_example

+ =(define-objc-method (class sel &key encoding callback) return-type lambda-list &body)= [Macro]

  #+begin_src lisp :exports results
  (documentation (macro-function 'define-objc-method) t)
  #+end_src

  #+RESULTS:
  #+begin_example
  Define ObjC instance method.

  Syntax:

      (define-objc-method (CLASS SEL &key ENCODING CALLBACK)
           RETURN-TYPE
           LAMBDA-LIST
        &body
        SELF...)

  + CLASS:
    literal string of ObjC class name
  + SEL:
    literal string of ObjC SEL name
  + ENCODING:
    method encoding type string
    if not given, will use class_replaceMethod with types as NULL pointer;
    if given, should be like a string starting with @:
  + CALLBACK
    custom CFFI callback symbol name
  + RETURN-TYPE:
    cffi return type with ObjC type enhanced
    + `:object'  same as :pointer
    + `:class'   return value will be wrapped as `objc-class-ptr'
    + `:sel'     return value will be wrapped as `sel-ptr'
    + otherwise see CFFI foreign types
  + LAMBDA-LIST:
    same as `cffi:defcallback'
  + BODY
    method body,
    within the BODY, self is bound to foreign-pointer of ObjC object
  #+end_example

+ =(define-objc-typing)= [Macro]

  #+begin_src lisp :exports results
  (documentation (macro-function 'define-objc-typing) t)
  #+end_src

  #+RESULTS:
  #+begin_example
  Define ObjC typing of NAME.

  Syntax:
  + NAME:  (recommanded to be) a keyword for ObjC typing name
  + ALIAS:
    + CFFI typing name
    + another ObjC typing NAME
  + RESULT:
    + CFFI type as `invoke' result
    + (CFFI-TYPE WRAP)
      + WRAP as `invoke' result wrap function
  + ARG:
    + CFFI type name as argument type
    + a list of (PATTERN EXPAND)

      + see `optima:match' for rule of PATTERN,
      + EXPAND will be evaluated to expand the result
      + if not PATTERN is matched, throw error when `expand-invoke-arg'
      + EXPAND can return two values (EXPAND REWRITE)
        + REWRITE will be used to wrap invoke like:

          (,@REWRITE (invoke ...))
  #+end_example
